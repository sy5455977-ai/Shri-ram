## 2025-05-26 - Optimized rendering and bundle size via code-splitting and prop-flattening
**Learning:** Passing volatile IDs (like `activeConversationId` or `copiedId`) to a list of memoized items causes O(N) re-renders because every item must re-evaluate its equality check. Flattening these to stable booleans (like `isActive` or `isCopied`) reduces re-renders to O(1) as only the affected items see a prop change. Additionally, code-splitting heavy mode components (`ChatInterface`, `VoiceMode`, `VisionMode`) reduced the initial entry bundle from ~1.3MB to ~117kB, significantly improving Time to Interactive.
**Action:** Always prefer boolean flags over raw IDs for items in a memoized list. Use `React.lazy` for any feature-heavy components that aren't part of the initial landing view.
