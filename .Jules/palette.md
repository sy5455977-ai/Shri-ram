## 2025-05-15 - Visual Feedback for Clipboard Actions
**Learning:** Transient visual feedback (e.g., toggling icons from 'Copy' to 'Check' for 2 seconds) is essential for confirming successful clipboard actions in asynchronous UI components where the user might otherwise be unsure if the action succeeded.
**Action:** Always implement a success state (like a 'Check' icon or 'Copied' text) when adding clipboard functionality to provide immediate confirmation.
