## 2025-05-14 - Interactive Feedback and Accessibility in Vision Systems
**Learning:** Visual-heavy modes like AI Vision often neglect keyboard-only users and lack immediate utility for output consumption. Adding ARIA labels to capture/reset actions and a 'Copy' utility with visual feedback significantly lowers the friction for users needing to move data from the analysis into other workflows.
**Action:** Always pair capture-based UI with immediate 'Copy' utilities and ensure all icon-only action buttons are screen-reader accessible via `aria-label`.
